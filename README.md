# IQ Challenge — Онлайн тести на логіку та кмітливість

Інтерактивний вебсайт із цікавими логічними завданнями та загадками для перевірки та розвитку мислення.

## Особливості проєкту
- Інтерактивні кнопки для приховування та показу відповідей за допомогою JavaScript.
- Сучасний адаптивний дизайн з використанням CSS-градієнтів та тіней.
- Підтримка мобільних пристроїв завдяки медіазапитам (`@media`).
- 6 унікальних запитань на кмітливість.

## Технології
- **HTML** (семантична розмітка)
- **CSS** (стилізація, адаптивність)
- **JavaScript** (інтерактивна логіка перемикання відповідей)

## Як запустити проєкт
1. Завантажте або клонуйте репозиторій.
2. Відкрийте файл `index.html` у будь-якому сучасному веббраузері.
